Sistema web para captar, ordenar y seguir interesados inmobiliarios.

Una web inmobiliaria conectada con formulario de captura, Google Sheets, CRM de interesados, emails automaticos, WhatsApp, Google Analytics y Meta Pixel.

3Google Sheets + email

El problema que resuelve.

Las consultas llegan desde distintos canales y se pierden cuando no hay registro, seguimiento ni una vista simple del estado comercial.

Consultas dispersas

Los interesados escriben por la web o WhatsApp, pero el equipo necesita una forma ordenada de registrar cada contacto.

Seguimiento manual

Sin estados claros es dificil saber quien es nuevo, quien fue contactado, quien tiene visita agendada y quien ya cerro.

Medicion incompleta

Google Analytics y Meta Pixel ayudan a entender el trafico y las acciones de marketing sobre la web inmobiliaria.

Funciones actuales del sistema.

Esta pagina muestra solamente funcionalidades que ya estan implementadas en la aplicacion.

Web inmobiliaria

Pagina publica de propiedades con detalle, galeria, llamados a WhatsApp y medicion con Analytics y Meta Pixel.

Captura de interesados

Formulario conectado a /guardar-interesado para registrar nombre, telefono, email, propiedad y mensaje.

Google Sheets

Los interesados se guardan en la hoja configurada y se crea respaldo local si la integracion no responde.

CRM de interesados

Panel /admin/interesados con listado de contactos y botones para actualizar estados comerciales.

Emails automaticos

Cuando entra un interesado, el sistema intenta enviar una notificacion por email usando la configuracion SMTP existente.

WhatsApp

La web incluye enlaces directos a WhatsApp y el sistema cuenta con endpoint de mensajes para conversaciones entrantes.

Beneficios para inmobiliarias.

Menos perdida de oportunidades, mas claridad comercial y una base ordenada de contactos para seguimiento.

01

Centraliza interesados

Cada consulta queda registrada con datos basicos y propiedad consultada.

02

Acelera respuestas

El equipo puede revisar el CRM y continuar por telefono, email o WhatsApp.

03

Ordena el seguimiento

Los estados permiten priorizar oportunidades segun avance comercial.

04

Mide acciones digitales

Analytics y Meta Pixel quedan activos en la web para evaluar trafico y campanas.
